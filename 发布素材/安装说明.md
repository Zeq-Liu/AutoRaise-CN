# AutoRaise 6.1 安装说明

## 系统要求

**macOS 14.0 (Sonoma) 及以上。** Apple Silicon（M1/M2/M3/M4）与 Intel 都支持，通用二进制。

**macOS 13 及以下不支持**，请不要安装。

> 为什么是 14.0 而不是更低：daemon 引擎本身只要 12.0，但整块设置界面是用 macOS 14 的
> SwiftUI API 重写的（`Form` + `.formStyle(.grouped)`、两参数版 `.onChange`）。
> 在 12/13 上会出现「图标出来了、鼠标悬停也有反应，但一点首选项就弹版本不足」。
> 本版直接把这个下限写进 `LSMinimumSystemVersion`，让系统层面拦住，避免装上才发现。

---

## 为什么需要手动处理

本应用是开源免费项目，**没有使用 Apple Developer ID 签名**（该证书需每年 $99 会员费）。
因此 macOS 的 Gatekeeper 会阻止首次打开，提示「无法打开，因为无法验证开发者」。

这不是应用有问题，是 macOS 对未签名应用的统一策略。下面两种方式任选其一。

---

## 方式一：一键脚本（推荐）

**第 1 步先做这个**：在 **`安装 AutoRaise.command`** 上 **右键 → 打开**，弹窗里点「打开」。
（从网上下载的脚本第一次必然被 Gatekeeper 拦，直接双击会看到「无法验证开发者」）

2. 终端窗口打开后，按提示输入本机登录密码
3. 脚本会自动完成：检查系统版本 → 备份旧版本 → 装到「应用程序」→ 去除隔离标记 → 校验签名
4. 结束时窗口会停住，按回车即打开 AutoRaise

> 如果右键打开后只启动了文本编辑器，说明 `.command` 的执行权限丢了。
> 在终端执行：`chmod +x 安装\ AutoRaise.command` 后再试。

> 安装失败时脚本会明确提示并停住，不会关闭窗口。任何一步失败都会中止，
> **你的原版本不会被破坏**（升级前已自动备份）。

---

## 方式二：手动拖拽

1. 把 **`AutoRaise.app`** 拖进「应用程序」文件夹
2. 打开「终端」，执行下面这行（去掉隔离标记）：

```bash
xattr -cr /Applications/AutoRaise.app
```

3. 在「应用程序」里双击 AutoRaise（若仍拦截，右键 → 打开 → 再点「打开」）

> 方式二不做重签，保留 DMG 内的原签名，实测可正常启动。
> 若日后系统更新导致授权失效，按下面「授予辅助功能权限」第 3 步重加一次即可。

---

## 必做：授予辅助功能权限

AutoRaise 靠 macOS 的「辅助功能」接口来提升窗口，**没有这个权限完全无法工作**。

1. 首次启动时会弹出系统提示，点「打开系统设置」
2. 在「隐私与安全性 → 辅助功能」中，勾选 **AutoRaise**
3. 若列表里已有 AutoRaise 但仍不生效：
   选中它，点「−」移除，然后重新添加 `/Applications/AutoRaise.app`

> 菜单栏图标变灰 = 没有权限。右键点图标 → 「授予辅助功能权限」可重新触发授权框。

> 重新安装或重新编译后 ad-hoc 签名会变，macOS 可能把旧授权判为失效，
> 此时按上面第 3 步移除再加一次即可。
>
> 菜单栏图标变灰 = 没有权限；菜单里「授予辅助功能权限」可以随时重新触发授权框。

## 基本用法

启动后菜单栏出现图标，程序常驻后台。把鼠标移到某个窗口上停留一小会儿，
该窗口会被提升并聚焦。

- **左键点图标** = 启停跟随功能
- **右键点图标** = 功能菜单（首选项 / 授予辅助功能权限 / 退出）

常用设置（右键 → 首选项）：

| 设置项 | 说明 |
|---|---|
| 鼠标停留多久后提升窗口 | 鼠标停在窗口上多久后提升。界面会直接显示**真实生效值**（按轮询次数取整） |
| 提升窗口后多久再聚焦 | 提升到聚焦之间的间隔，同样显示真实值 |
| 轮询间隔 | 检测频率，默认 50ms。越小越灵敏，越费电 |
| 忽略的应用 | 不参与自动提升的应用，**英文逗号**分隔（填中文逗号会自动纠正） |
| 忽略的窗口标题 | 正则匹配，英文逗号分隔 |
| 临时停用方式 | 按住 control 暂停 / 仅按住 control 启用 等五种 |
| 启停跟随功能的全局快捷键 | 改完立即生效 |

> 全新安装后如果什么都不动就直接用，默认值（停留 300ms）已经可用。

---

## 卸载

1. 右键点菜单栏图标 → 退出
2. 把 `/Applications/AutoRaise.app` 拖进废纸篓
3. （可选）清理配置：

```bash
defaults delete com.autoraise.app
```

4. （可选）在「系统设置 → 隐私与安全性 → 辅助功能」中移除 AutoRaise 条目
